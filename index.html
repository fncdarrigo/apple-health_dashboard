🩺 Apple Health Dashboard

Analisi dati avanzata

📖 Guida: Come usare la Dashboard

1

📱 Esporta dati da iPhone

  1. Apri l'app Salute sul tuo iPhone
  2. Tocca la tua foto profilo in alto a destra
  3. Scorri in basso e seleziona "Esporta tutti i dati sulla salute"
  4. Attendi la preparazione (può richiedere alcuni minuti)
  5. Scegli "Salva su File" e salva lo ZIP su iCloud Drive o sul dispositivo

💡 Il file ZIP contiene un file export.xml con tutti i tuoi dati.

2

🔄 Converti XML in CSV

L'XML di Apple Health non è leggibile direttamente. Devi convertirlo in file CSV (uno per metrica).

Opzioni consigliate:
  • 📱 Health Export (iOS App) — App nativa, converte direttamente su iPhone, esporta CSV per categoria
  • 🐍 Apple Health Export (Python) — pip install apple-health-export → apple-health-export export.xml --format csv
  • 🌐 HealthKit to CSV (Web) — Trascina export.xml su healthkit-to-csv.vercel.app (nessun upload, tutto lato client)
  • 💻 Script Python personalizzato — Per controllo totale (vedi esempio sotto)
Esempio script Python:
import xml.etree.ElementTree as ET
import csv
from collections import defaultdict

tree = ET.parse('export.xml')
root = tree.getroot()

records = defaultdict(list)
for record in root.findall('.//Record'):
    date = record.get('startDate')[:10]
    metric = record.get('type').replace('HKQuantityTypeIdentifier', '')
    value = float(record.get('value'))
    records[metric].append((date, value))

for metric, data in records.items():
    with open(f'{metric}.csv', 'w', newline='') as f:
        writer = csv.writer(f)
        writer.writerow(['date', 'value'])
        writer.writerows(sorted(data))
3

📊 Importa in Dashboard

  1. Clicca "Scegli file" (o trascina i CSV nell'area di upload)
  2. Seleziona più file CSV contemporaneamente (⌘/Ctrl + clic)
  3. Le metriche appariranno come pulsanti sotto "Metriche caricate"
  4. Clicca una metrica per visualizzare grafici, statistiche e Top 10
  5. Usa i filtri data ("Ultimo Anno", "Tutto", o date personalizzate)

💡 La dashboard supporta: Passi, Frequenza cardiaca, Allenamenti, Peso, Calorie, Distanza, Sonno, VO2 Max, HRV, Ossigeno, Pressione, Glicemia, Temperatura.

4

🔍 Funzionalità avanzate

  • Correlazione: Seleziona due metriche e clicca "Analizza" per vedere correlazione di Pearson
  • Top 10 Giorni: Nella sidebar, vedi i giorni con valori massimi per la metrica attiva
  • Esportazione: Scarica grafici come PNG o tutti i dati come CSV
  • Media mobile 7gg: Nel grafico distribuzione, linea arancione = trend settimanale
